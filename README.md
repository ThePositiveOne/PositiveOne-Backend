> 
> 바쁜 일상 속에서 놓치기 쉬운 작은 긍정의 순간들을 기록하고,
> 
> 다른 사람들과 따뜻한 에너지를 공유할 수 있는 커뮤니티형 다이어리 서비스입니다.
